# Contributing

Thanks for helping improve the Dugble Node SDK.

## Development setup

1. Install dependencies with `npm install`.
2. Run the test suite with `npm test`.
3. Build the package with `npm run build`.

## Guidelines

- Follow the existing TypeScript style.
- Add or update tests for any behavior change.
- Keep changes focused and well documented.

## Pull requests

Please open a pull request with a concise summary of the change and any relevant context.
